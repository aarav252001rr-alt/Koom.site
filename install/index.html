QUICK SETUP

Get KOOM on your device.

Installation takes just a moment. Choose the steps for your device.

◉

Android

Chrome and supported browsers

  1. Open koom.site in Chrome.
  2. Tap Install KOOM above, if available.
  3. If no prompt appears, open the browser menu ⋮ and choose Install app or Add to Home screen.
⌘

iPhone / iPad

Safari

  1. Open koom.site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.

Install availability depends on your browser and the site's PWA configuration. If the install button isn't available, use the manual steps above.
